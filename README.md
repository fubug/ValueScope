# 投资面板（ValueScope v4）

一个纯静态的投资决策面板：**全球主要市场估值对比 + A 股个股价值分析 + 行业看法**。
Astro 构建，GitHub Pages 自动部署，数据就是仓库里的 JSON，改完提交即上线。

## 在线访问

`https://fubug.github.io/ValueScope/`（push 到 main 后 1-2 分钟自动部署）

## 页面结构

| 路径 | 内容 |
|---|---|
| `/` | 全球市场横向对比：PE / PB / 股息率 / 估值分位 / ERP / 性价比档位 |
| `/markets/[id]` | 单市场详情：5/10/20 年分位、口径问题、判定链、人工结论 |
| `/stocks` | A 股个股：三层过滤器总表（卡在哪一层一眼可见）+ 按距买入价排序的分组 |
| `/stocks/[ticker]` | 个股详情：三层校验、合理价值区间、估值方法、反证条件 |
| `/etfs` | ETF 工具：底层指数估值 + 三层（成本/估值/可用），溢价换算成费率年数 |
| `/etfs/[code]` | ETF 详情：溢价警示、三层校验、申购状态、指数口径提示 |
| `/etfs/dividend` | 红利低波体检（ETF 模块的子页，从 `/etfs` 的入口卡片进入）：绝对锚与相对锚的冲突、股债利差拆解、银行集中度、工具费率对比 |
| `/undervalued` | 低估值扫描：破净分布、股息分层，以及「为什么这些板块测不准」 |
| `/sectors` | 行业看法：每条观点必须带反证条件 |
| `/method` | 方法论：判定规则、数据来源、已知局限 |

## 设计原则

1. **没有综合评分。** 上一个版本（v3）的五维加权「鱼情分」被废弃：权重是拍的，没人验证过分数与收益的关系。现在只用「主估值分位落档 + ERP 修正」两步，每步可复算、可反对。
2. **缺数据就留空，不编数字。** 页面上所有「待接入」都是真实缺口（如长期年化/夏普），比一个好看的假数字有价值。
3. **每个观点必须可推翻。** 行业观点与个股分析都强制携带「反证条件」，条件出现就必须改结论。
4. **便宜和该买是两件事。** 「便宜但不买」是独立分类，防止把低估值当买入理由。
5. **规则派生，不手填结论。** 个股的 status 与买入价由三层过滤器计算得出（绝对锚 → 相对锚 → 反证），`data/stocks.json` 没有 `buyZone` 字段，手填会被校验拒绝；ETF 同理由成本/估值/可用三层派生。
6. **确定性决定证据强度。** 个股折价门槛按确定性分 12%/22%/32%；ETF 的估值分位自带可信度分级（指数发布日 + 编制变更写进数据，样本不可比时即使分位通过也只判部分通过）。
7. **PE 分位与 PB 分位打架时，看 ROE。** PB ÷ PE 就是 ROE，所以「PB 分位低但 PE 分位高」不是数据错误，是净资产还在、赚钱能力退了——这种便宜是假便宜（沪深300：PE 分位 69%、PB 分位 20%、ROE 9.87%）。反向同样成立（标普500：PE 分位 41%、PB 分位 96%、ROE 23.3%）。
8. **矛盾的指标不能挑一把用。** 红利低波同时出现「绝对锚通过（利差 3.02pct）」和「PE 5 年分位 99.7%」，正确做法是把两把尺子的冲突摊开讲清成因（贴现率下降推高 PE，而非盈利恶化）。
9. **成本有绝对阈值，也有相对锚。**费率 0.60% 在 1.0% 上限内「合格」，但同指数有 0.20% 的同款产品时，多付的 0.40pct/年买不到任何东西（港股通互联网：513040 与 513770 同为 52 亿规模、日均 4.6 亿成交、跟踪同一个 931637，费率差 3 倍，一年间份额 +5% vs −34%）。同指数费率高出最低者 0.2pct 且达 1.5 倍时，成本层自动降为「部分」并在费率列下标注「最低 X%」——只降级不否决，大产品的流动性溢价留给人判断。
10. **QDII 的折溢价只看 IOPV。** 净值 T+1 确认，「价格÷净值」会算出不存在的折价（同日 −2.34% vs IOPV −0.27%）；高溢价 + 暂停申购（161125 溢价 6.1% ≈ 7.6 年费率）则相反，是失去回归机制的真溢价。
11. **遗漏在 CI 就被拦住。** `npm run check` 直接 import 页面用的同一份规则模块：漏填 `certainty`/`payoutRatio`/`veto`、手填 status 与派生不一致、ROE ≠ PB/PE、新指数用 10 年分位却不解释回溯段——任何一条都让部署失败。
12. **PE 为负时，PE 分位不作数，换 PB 也要打折。** 指数整体亏损时（光伏产业 931151：整体法 PE −65.91，官网口径却显示 22.54 倍——前者计入亏损公司，后者剔除了它们），负数照样能排出百分位，但那名次衡量的是「亏得多深」，行业越亏分位可能越「便宜」，方向是反的。规则硬编码：PE ≤ 0 → 估值层改用 PB 分位，且最高只判「部分通过」——因为 ROE 同样为负，PB 的分母（净资产）正被亏损吃掉，低 PB 是价值陷阱的形态，不是安全边际。背离表自动排除负 PE 指数（它们的 PE/PB 差是「亏损扩大」，不是「ROE 下行」）。
13. **分位可信 ≠ 分位可比：窗口里套着泡沫时，两个都摆出来。** 光伏那类问题是「样本不够」（回溯模拟、编制变更，分位算得不对）；白酒是另一类——2014-12-10 发布、11.9 年历史、样本完整、可信度「高」，但十年分位 25.08 与三年分位 76.59 同时成立。矛盾不在样本，在锚：2021 年把 PE 推到 50–60 倍，把十年窗口的上界抬到了一个大概不会再回去的位置，今天 22 倍自然显得「只有历史四分之一」，可对 2023 年以后进场的人这段历史里从没有过 22 倍以下。规则硬编码（percentileWindowConflict）：长窗口 ≤35 且短窗口 ≥65 → 判窗口分歧，估值层不得判通过，且页面上两个分位必须并排出现，不许只留一个看起来便宜的数。配套规则 impliedPayoutRatio：股息率 × PE 反解隐含派息率，超过 80% 说明「高股息」是分子滞后于分母的时点差（白酒 4.15% × 22.26 = 92%），绝对锚只能算「看起来过了」，不能当可持续的现金回报。
14. **同一个东西出现两个价钱时，「贵」和「便宜」都不能下结论。** 光伏那次的 -65.91 对 22.54 差 88 倍，一眼能看出口径不同；电力的 22.43 对 17.75 只差 21%，两个都像正常市盈率，但整体法分位 73%（偏贵）、剔除亏损口径分位 25.84%（便宜）——结论相反。差的来源是分母里有没有亏损样本：整体法回答「整个行业按利润回本要几年」，剔除亏损回答「赚钱的那部分要几年」。规则硬编码（peSourceConflict / PE_SOURCE_GAP=0.2）：同日两口径差超过 20% → 估值层最高只判部分通过，且 peCaveat 必须写明差异来源；validate 检测到「一贵一便宜」时输出警告。给一个数比给两个数更需要理由——说不清就是说不清，不要替市场选一个。
15. **「买哪只」和「什么时候买」必须分开算，不能 AND 成一个词。** 2026-11 审计发现旧的三层模型把三件事（beta 要不要 / 现在是不是时候 / 买哪只工具）AND 成「可配置/需观察/回避」，25 只里 22 只判需观察，而工具最好的 510300 与费率是最低档 3 倍的 561560 显示同一个词；且「可配置」被指数层锁死——估值判的是指数，同指数下所有 ETF 共享同一结论，指数贵则工具再好也永远不可配置。重构为两维：工具分只在同指数内比较（费率最低档 + 成交 ≥0.5 亿 → 同类最优；落后但差幅未达 0.2pct/1.5 倍 → 竞争档；费率达相对锚或流动性不足 → 落后），入场分只判指数（便宜/中性/偏贵/说不清，证据链有一环不可靠就不给方向）。两维组合出六个动作：可配置/换工具/等时机/不参与/回避/待核——六个动作的补救方式完全不同，这是分开记录的理由。配套不变量进 CI：可配置必须两维同时成立；回避只能由溢价触发；待核必须真的缺「决定能不能买」的数据；建议换工具必须真的存在同类最优替代品；单一动作占比超 60% 报警（防模型塌回一个筐）。

## 数据维护

```bash
npm install
npm run check   # 数据校验（字段完整性 + 新鲜度，提交前必跑）
npm run dev     # 本地开发 http://localhost:4321/ValueScope/
npm run build   # 构建到 dist/
```

| 文件 | 改什么 |
|---|---|
| `data/markets.json` | 市场估值快照。改 `snapshot` 日期，核对分位口径后填入 `percentiles` |
| `data/stocks.json` | 个股。新增一只必须填 `certainty`（高/中/低确定性）、`payoutRatio`、`anchorNote`、`veto`；status 与买入价自动派生，不要手填 |
| `data/etfs.json` | ETF 工具。indices 放底层指数估值（必须带 sources 与口径说明；PE/PB 分位差超 30pct 必须填 `roe`，校验强制 roe = PB/PE），etfs 放工具成本（溢价/费率/申购状态）。溢价为空必须用 note 说明，填了必须与 price/nav 自洽 |
| `data/screen.json` | 低估值扫描的板块级统计（破净分布、盲区说明），不放个股结论 |
| `data/dividend.json` | 红利低波专题。所有派生数字（派息率、利差、情景利差）都会被校验复算，手改结论而不改输入会被 CI 拒绝 |
| `data/sectors.json` | 行业观点，更新 `pePercentileBasis` 的数据日期 |

## 已知缺口

- **长期年化收益 / 夏普比率 / 最大回撤**：所有市场均未接入。免费行情接口（stooq / Yahoo / 东财）在本环境不可用。补数方式：把指数月度收盘价放到 `data/series/<id>.csv`，脚本自动计算（待实现），比抄第三方数字可信。
- **欧洲 STOXX 600**：本次快照未取得可信估值，字段留空。
